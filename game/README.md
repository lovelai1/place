# Roblox Studio game structure

This folder mirrors the initial Roblox Studio hierarchy for the project.

```text
game
├── ServerScriptService
├── ReplicatedStorage
├── StarterPlayer
│   ├── StarterPlayerScripts
│   └── StarterCharacterScripts
├── StarterGui
└── Workspace
    ├── Camera
    ├── Baseplate
    │   └── Texture
    ├── Terrain
    └── SpawnLocation
        └── Decal
```

Empty folders contain `.gitkeep` placeholders so Git preserves the structure.
