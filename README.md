# Roblox Studio проект (структура для GitHub)

Базовая структура папок для проекта Roblox Studio в репозитории.

## Структура

- `src/ReplicatedStorage` — общие модули/ресурсы для клиента и сервера.
- `src/ServerScriptService` — серверные скрипты.
- `src/StarterPlayer/StarterPlayerScripts` — клиентские скрипты игрока.
- `src/StarterGui` — интерфейсы.
- `src/Workspace` — объекты мира.
- `src/Lighting` — настройки освещения.
- `src/SoundService` — настройки и звуковые ресурсы.
- `src/Teams` — команды.

Папки содержат `.gitkeep`, чтобы структура сохранялась в Git до добавления реальных файлов.
